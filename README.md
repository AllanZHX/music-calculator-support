## Local verification

Run `python3 -m unittest discover -s tests -v`, then serve the repository root with `python3 -m http.server 4173 --bind 127.0.0.1`.

## Content changes

Update Chinese and English counterparts together. Keep their section IDs, version numbers, effective dates, and material rights aligned. Run the full test suite before publishing.

## Privacy

This website intentionally contains no advertising, analytics, trackers, remote fonts, forms, or nonessential cookies.
